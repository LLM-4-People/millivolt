operator surface

Control from the same surface.

These are operator actions, not per-user permissions. The same shared token protects the dashboard and the inference listener.

  • PauseHold new sends and retries by client, provider, or all traffic.
  • LimitsSet provider-wide concurrency, request-rate, and token-rate policies.
  • DebugCapture scoped bodies with a timed or manual stop; captured bodies stay sensitive.
  • ExportDownload exactly the finalized records you filtered as gzip JSON.
  • RestartDrain and hand off supported source deployments.
  • SettingsEdit typed fields and rules with revision-checked changes.

run it

Three commands and a browser tab.

Linux with Docker Engine and the Compose plugin. No Go, Node, or source checkout is needed for the container path.

sh
curl -fsSL \
  https://raw.githubusercontent.com/LLM-4-People/millivolt/main/compose.yaml \
  -o compose.yaml
export MILLIVOLT_OPERATOR_TOKEN='replace-with-a-long-random-value'
docker compose up -d

Open http://127.0.0.1:8080/ and sign in with that token.

  1. Fetch the deployment file.The image is published for amd64 and arm64. Named volumes retain history and saved settings.
  2. Set the operator token.One shared credential protects the dashboard and inference listener. With it unset, the dashboard denies every request.
  3. Connect your client.Use http://127.0.0.1:8080/v1 as the API base URL. Your upstream key is forwarded; it does not authenticate the dashboard.
Exposure is the boundary.

Keep the listener on loopback, or put an authenticated proxy in front. There are no user accounts. Read security before network exposure.

Connect a client.

Point an OpenAI-compatible client at http://127.0.0.1:8080/v1. Send your upstream base URL in X-Proxy-Base-URL, your upstream key in Authorization, and an optional label in X-Proxy-Client. The proxy does not register providers or keys.

Architecture and ownership · MCP server

fit and limits

What it is not.

millivolt is built for a single operator or small team that controls the host. The limits are part of the contract, not a footnote.

tenancy

One operator, no user isolation.

A single credential protects the dashboard and inference listener. There are no per-user accounts or tenant boundaries.

durability

Best-effort accounting.

Sustained overload can drop records even when inference succeeds. The dashboard warns about process-local storage drops.

scope

Observability, not billing.

Cost is provider-reported. This is not an independent invoice, a complete audit log, or a compliance system.
